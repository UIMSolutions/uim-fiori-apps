# UML Diagram Manager (Fiori 3 + OData V4 + vibe.d)

This app provides:
- Create UML diagrams
- Manage and update diagrams
- Display stored diagrams
- Draw UML elements on a canvas (class, actor, association, inheritance, note)

## Start locally

```bash
cd backend
dub run
```

Open:
- App: http://localhost:8080/
- OData root: http://localhost:8080/odata/v4/UmlService/
- Metadata: http://localhost:8080/odata/v4/UmlService/$metadata
