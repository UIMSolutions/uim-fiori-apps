# CAD Drawing Manager (Fiori 3 + OData V4 + vibe.d)

This app provides:
- Create CAD drawings
- Manage and update drawings
- Display stored drawings
- Draw directly on a canvas (pen, line, rectangle)

## Start locally

```bash
cd backend
dub run
```

Open:
- App: http://localhost:8080/
- OData root: http://localhost:8080/odata/v4/CadService/
- Metadata: http://localhost:8080/odata/v4/CadService/$metadata
